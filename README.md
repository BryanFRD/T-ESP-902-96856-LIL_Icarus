# Icarus web app

Application web de l’outil Icarus pour le pentest.

## Prérequis

- Node v23 ou supérieur
- Pour toute question ou accès, contacter : arthur.azoula@epitech.eu, antoine.ousselin@epitech.eu ou bryan.ferrando@epitech.eu

## Lancer le projet

### 1. Cloner le dépôt

```bash
git clone <repo_url>
```

### 2. Installer les dépendances

```bash
npm install
```

### 3. Démarrer en fonction de l'environnement pour utiliser les différentes apis

Local

```bash
npm run local # Propre api locale
```

Dev

```bash
npm run dev # Api de dev (https://api-dev.icarus-cyber.fr)
```
